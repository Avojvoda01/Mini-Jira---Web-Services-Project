Mini Jira has users and admin user management.

A user has:
- Id
- Email
- DisplayName
- Role
- CreatedAtUtc
- UpdatedAtUtc

The UserDto returned by the API does not expose PasswordHash.

Known roles:
- Admin
- Project Manager
- Project Member

Important auth routes:
- POST /api/auth/register registers a new user.
- POST /api/auth/login logs in a user and returns a token.

Important user/admin routes:
- GET /api/users gets users.
- GET /api/users/{userId} gets one user.
- GET /api/admin/users gets all users for admin.
- GET /api/admin/users/{userId} gets one user for admin.
- POST /api/admin/users creates a user as admin.
- DELETE /api/admin/users/{userId} deletes a user as admin.
- PATCH /api/admin/roles/{userId} changes a user's role.

Changing a role accepts Admin, Project Manager, or Project Member.
