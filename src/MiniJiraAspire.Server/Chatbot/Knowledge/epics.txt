Epics are larger feature groups inside Mini Jira.

An epic belongs to one project.
Tasks can be assigned to an epic.

Where users find epics in the app:
Epics are found inside a project workspace on the Backlog page.
To find epics, sign in, open Projects, choose a project with Open project, then click Backlog in the left sidebar.

What users can do with epics on Backlog:
- view all epics for the current project
- sort epics
- create an epic with Create epic
- edit an epic
- delete an epic
- assign unassigned tickets to an epic
- remove tickets from an epic

If a user asks where epics are, give the full click path in a friendly way.
Example answer: To find epics, go to the Projects page, open the project you want, then click Backlog in the left sidebar. The Backlog page is where epics are shown and managed.

Use epics when several tasks are part of one bigger feature.
Example: an Authentication epic could contain login, register, password reset, and role management tasks.
