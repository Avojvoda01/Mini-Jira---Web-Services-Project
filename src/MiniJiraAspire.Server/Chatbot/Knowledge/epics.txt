Epics are larger feature groups inside Mini Jira.

An epic has:
- Id
- Name
- Description
- ProjectId
- CreatedAtUtc
- UpdatedAtUtc

An epic belongs to a project through ProjectId.
Tasks can be assigned to an epic.

Important epic routes:
- GET /api/epics gets all epics.
- GET /api/epics/{id} gets one epic by id.
- POST /api/epics creates an epic.
- PUT /api/epics/{id} updates an epic.
- DELETE /api/epics/{id} deletes an epic.

Use epics when several tasks are part of one bigger feature.
Example: an Authentication epic could contain login, register, password reset, and role management tasks.
