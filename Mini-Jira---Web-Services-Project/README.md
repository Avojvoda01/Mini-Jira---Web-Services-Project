# Mini Jira Web App

A lightweight Jira-inspired task management web application built to manage projects, track tasks, and collaborate efficiently.

---

# Mini Jira Web App – Use Cases & Features

## Roles / Actors

### Admin

* Manage users and roles
* Oversee all projects
* Configure system settings

### Project Manager

* Create and manage projects
* Assign tasks to team members
* Set priorities, labels, and epics
* Monitor project progress

### Project Member

* View assigned tasks
* Update task status
* Collaborate via comments or chat
* Track personal workload

---

## Core Features (Must Have)

### Task Management

* Create, edit, and delete tasks
* Update task **status** (To Do, In Progress, Done)
* Set **priority levels** (Low, Medium, High)

### Assignment & Organization

* Assign tasks to users
* Group tasks using **epics / labels**

### Search & Filtering

* Filter tasks by:

  * Assigned user
  * Priority
  * Status
* Quick search functionality

### Project Dashboard

* Kanban board (Backlog → In Progress → Done)
* Overview of project progress

### Authentication

* User **sign up / login**
* Role-based access control

---

## Advanced Features (Nice to Have)

### SLA Tracking

* Define time limits for tasks
* Monitor deadlines and delays

### Task Escalation

* Automatically flag overdue tasks
* Notify managers when deadlines are missed

### Notifications

* Email alerts for:

  * Task assignment
  * Status updates
  * Escalations

### Mini Calendar

* View tasks by due date
* Schedule and plan work visually

### Activity History

* Track all updates on a task
* Audit trail of changes

### Real-Time Collaboration

* Live chat between team members
* Task-based discussions

### AI Assistant (Optional Enhancement)

* Suggest task priorities
* Auto-generate task descriptions
* Provide productivity insights

```bash

# Go into the project folder

# Install dependencies
npm install

# Run the app
npm start
```

## How It Works

* Tasks are created and stored in the database
* Each task has a status and can move across columns
* Users can update tasks in real time
